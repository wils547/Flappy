🐤 Flappy

🎮 About The Game

Flappy is a simple arcade-style game inspired by the legendary Flappy Bird.

Your mission is simple:

«Control the bird, avoid the pipes, and survive as long as possible.»

The longer you survive, the higher your score.

This project was built from scratch using vanilla JavaScript and HTML Canvas, featuring custom game logic, physics, score system, countdown, sound effects, and responsive gameplay.

---

✨ Features

✅ Smooth bird movement physics
✅ Pipe obstacle generation
✅ Collision detection system
✅ Score tracking system
✅ Countdown before starting game
✅ Start & restart menu overlay
✅ Sound effects for scoring and game over
✅ Mouse click & keyboard controls
✅ Pure HTML, CSS, and JavaScript (No Framework)

---

🕹️ Controls

Action| Control
Jump| "Space"
Jump (Mouse)| "Left Click"

---

📸 Gameplay

Try to survive by flying through randomly generated pipe gaps.

- Avoid hitting the top pipe
- Avoid hitting the bottom pipe
- Don't fall to the ground
- Beat your highest score 🚀

---

🧠 Tech Stack

- HTML5 Canvas
- CSS3
- Vanilla JavaScript

No libraries. No frameworks. Just pure web game development.
